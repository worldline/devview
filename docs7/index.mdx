---
title: DevView
description: In-app developer tools for Kotlin Multiplatform apps on Android and iOS.
---

DevView adds an in-app developer menu to Kotlin Multiplatform applications. Choose modules for feature flags, analytics inspection, network mocking, and screen state history.
