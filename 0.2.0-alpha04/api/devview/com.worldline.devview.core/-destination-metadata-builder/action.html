action

fun action(icon: ImageVector, popup: ModuleDestinationActionPopup? = null, action: () -> Unit)

Adds a contextual action to this destination's top app bar.

Each action is rendered as an IconButton. If popup is provided, a confirmation dialog is shown before action is invoked.

Action scope

The action lambda is captured once at module construction time. It is therefore best suited for calls that are lifecycle-independent:

  • Module-owned singletons — the simplest and most common case:

action(icon = Icons.Rounded.Delete) { AnalyticsLogger.clear() }
Content copied to clipboard

  • Cross-boundary commands (e.g. triggering a ViewModel) — use a SharedFlow on the module as an event bus, then observe it at the call site where the ViewModel is available:

// In the module
val onClearRequested = MutableSharedFlow<Unit>(extraBufferCapacity = 1)
// ...
action(icon = Icons.Rounded.Delete) { onClearRequested.tryEmit(Unit) }

// In the host Composable, where the ViewModel is in scope
LaunchedEffect(myModule) {
    myModule.onClearRequested.collect { viewModel.clearData() }
}

This keeps the module decoupled from the host app's DI graph while still allowing ViewModel functions to be triggered safely.

Parameters

icon

The icon to display for this action button.

popup

Optional confirmation dialog shown before action is invoked. Pass null (the default) to invoke action immediately on tap.

action

The callback invoked when the action is confirmed (or tapped directly if no popup is provided).
