fun create(statusCode: Int, exampleName: String, content: String, statusTextProvider: (Int) -> String = ::getStatusText): MockResponse

Creates a MockResponse, generating a human-readable MockResponse.displayName from statusCode and exampleName.

The "default" example name (by convention, the primary response for a status code) contributes no suffix to the display name; any other example name is title-cased and appended (e.g. exampleName = "not-found-detailed" → "Not Found - Not Found Detailed (404)" is avoided by keeping example names short and specific, e.g. "detailed" → "Success - Detailed (200)").

Return

A MockResponse with a generated MockResponse.displayName

Parameters

statusCode

The HTTP status code

exampleName

The OpenAPI example name

content

The raw response body

statusTextProvider

Optional lambda that maps a status code to its display text. Defaults to the built-in getStatusText mapping.
