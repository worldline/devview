# Prerequisites

Before integrating DevView, ensure your development environment meets the following requirements:

## Project Requirements
- **Kotlin Multiplatform Project**: Your project should be set up for Kotlin Multiplatform development.
- **Compose Multiplatform**: Compose Multiplatform must be configured and working in your project.

## Minimum Supported Versions
<!-- renovate: datasource=maven depName=org.jetbrains.kotlin:kotlin-stdlib -->
- **Kotlin**: 2.4.10 or newer
<!-- renovate: datasource=maven depName=org.jetbrains.compose:compose-gradle-plugin -->
- **Compose Multiplatform**: 1.11.1 or newer
- **Android**: API level 26 (Oreo) or higher
- **iOS**: iOS 16.0 or higher

## Development Tools
- **IDE**: Android Studio Giraffe or newer (recommended for best Compose Multiplatform support)
- **Gradle**: 8.0 or newer

## Additional Recommendations
- Ensure your project builds and runs successfully on all intended platforms before integrating DevView.
- Familiarity with Gradle and Kotlin Multiplatform concepts will help you get started quickly.

## Troubleshooting
If you encounter issues with your environment setup, refer to the [troubleshooting section](troubleshooting-faq.md) for common solutions and tips.

---

_This section is intended for developers of all experience levels. If you are new to Kotlin Multiplatform or Compose, consider reviewing the official documentation for these technologies before proceeding._
