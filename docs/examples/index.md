## Sample Code
Check the `sample/` directory in the repository for complete working examples.
The sample groups Compose, TimeCapsule and Network demonstrations into labelled sections;
Open DevView is the primary action. Network results appear in a scrollable page with a
monospace result card. Hiding the Counter Screen disposes its recording and resets its history.

The FeatureFlip Dark Mode flag controls the sample theme and Android system-bar icons,
including the navigation-bar background on API 26–28. iOS system-bar appearance remains
owned by the sample host controller.
