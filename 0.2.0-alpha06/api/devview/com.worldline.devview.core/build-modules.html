buildModules

fun buildModules(block: ModuleRegistry.() -> Unit): ImmutableList<Module>

DSL function for creating a module configuration.

This function provides a clean, declarative way to build a list of DevView modules. The returned list is immutable and can be safely passed to the DevView composable.

Basic Usage

val modules = buildModules {
    module(AppInfo)
    module(FeatureFlip)
    module(Analytics)
}

Adding Multiple Modules

val modules = buildModules {
    module(AppInfo)
    modules(FeatureFlip, Analytics, Console)
}

Conditional Modules

val modules = buildModules {
    module(AppInfo)

    if (BuildConfig.DEBUG) {
        module(DebugTools)
    }

    if (hasFeatureFlagsEnabled) {
        module(FeatureFlip)
    }
}
